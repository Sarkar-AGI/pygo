# Changelog

All notable changes to PyGo are documented here.

## [0.1.0] - Initial release

### Added

- Go-first application architecture.
- Native C++ tensor/runtime layer.
- Python ecosystem for higher-level framework functionality.
- CGo/C ABI bridge infrastructure.
- Embedded CPython and pybind11 integration sources.
- CPU and optional CUDA execution paths.
- Native, Python and Go CI workflows.
- Architecture, installation, quickstart and release documentation.

### Release policy

Hardware-specific support is only considered validated when the corresponding build and runtime tests pass on that hardware.
